VoiceStudio — бесплатный ElevenLabs на твоём компе

Открытый проект на GitHub (лицензия AGPL-3.0): клон голоса, дизайн голоса, дубляж видео, диктовка, расшифровка и аудиокниги — на 646 языках. Всё считается на твоём компьютере, без аккаунта и подписки. Октябрь 2026.

Открыть VoiceStudio на GitHub
  1. 01

    Что нужно

    • Mac на Apple Silicon (M1 и новее) — быстро, через Metal.
    • Windows или Linux — с видеокартой NVIDIA быстрее, без неё работает на процессоре, просто медленнее. Нужно около 5 ГБ на диске.
    • Mac на Intel — только интерфейс, считать придётся на другом компьютере.
  2. 02

    Поставь одной командой

    Mac и Linux — в Терминале:

    curl -fsSL https://voicestudio.sh/install | sh

    Windows — в PowerShell:

    irm https://voicestudio.sh/install | iex

    Команды — из официального README. Без терминала: скачай установщик (.dmg / .exe / .AppImage) в Releases.

  3. 03

    Или пусть поставит Клод

    Вставь в Claude Code (или Codex, Cursor):

    Установи приложение VoiceStudio (Electron) на этот компьютер и проверь, что оно работает. Действуй по инструкции https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md

    Агент сам определит железо и спросит перед скачиванием моделей.

  4. 04

    Первый клон

    • Открой Voice cloning.
    • Добавь чистую запись своего голоса — в тишине, без музыки и эха.
    • Напиши текст и нажми Synthesize. Нужную модель приложение предложит скачать само.
  5. ЕЩЁ

    Что там есть кроме клона

    • Дубляж: загрузи видео — расшифрует, переведёт и озвучит тем же голосом.
    • Диктовка: плавающий микрофон печатает текст в любое окно.
    • Расшифровка с разметкой, кто что сказал.
    • Аудиокниги и пакетная озвучка.
    • Локальный API и MCP — можно подключить к агентам.
  6. ВАЖНО

    Честно

    • Клонируй только свой голос — или с согласия человека. В приложении есть водяной знак ИИ.
    • Как звучит русский, зависит от записи и модели — попробуй на своём голосе.
    • Делаешь на его коде свой продукт — сначала прочитай лицензию AGPL-3.0.
